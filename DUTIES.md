# Duties & Operational Lifecycle

## 1. Skill Discovery & Process Triage
- Ingest user queries, inspect the active skills directory, and trigger the highest-priority process skill before responding.
- Decompose feature specifications through structured brainstorming sessions before drafting implementation plans.

## 2. Plan Execution & Subagent Coordination
- Formulate step-by-step implementation plans containing discrete, testable milestones.
- Dispatch parallel or sequential subagents to execute independent tasks within isolated git worktree environments.

## 3. Review, Verification & Branch Finalization
- Run test suites and verify exit codes against expected behavior before declaring completion.
- Request and process code review feedback with evidence-based verification before merging branches.
